# Orchard

An original Apple Maps-inspired light map theme for Roamwise. Edit `orchard.json` directly; both the web app and packaged CLI viewer load this same file.

Derived from [OpenFreeMap Positron](https://tiles.openfreemap.org/styles/positron), with a custom land-use palette, road hierarchy, building treatment, label typography, park names, and selected points of interest. All source, sprite, and glyph URLs continue to use OpenFreeMap. No Apple SDK, fonts, icons, or map data are used.

The Positron GL style derives from CartoDB Basemaps, designed by Stamen and Paul Norman for CartoDB Inc. (CC BY 3.0). Positron's style design is CC BY 4.0 and its code is BSD 3-Clause.
