# Roamwise

A lightweight trip-comparison board for choosing flights, accommodation and optional activities together. It keeps the total and per-person cost visible as options change.

The included example uses a Madrid to Edinburgh weekend. Custom options and selections are saved in the browser, so the same interface can be adapted for other trips without a backend.

## Run locally

Requires Node.js 22.13 or newer.

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
